# Discovering Kids Consultation Service

Official website for **Discovering Kids Consultation Service**, providing high-quality early intervention, Specially Designed Instruction (ABA), and inclusive preschool education for children across Maine.

## Website Pages

- **Home (`index.html`)**: Overview of services, dual pathways to growth, mission, and calls to action.
- **About (`about.html`)**: Detailed mission, program overview, Chapter 124 compliance, and *Pre-K for ME* curriculum alignment.
- **Our Team (`team.html`)**: Bios and qualifications for Founder & Director Allen Tomasello (BCBA, M.Ed.), Lead Teacher Erica Hughes, and Lead Teacher Melanie Fessler.
- **Testimonials (`testimonials.html`)**: Direct feedback and stories from parents and caregivers.
- **Contact (`contact.html`)**: Location details, hours, contact information, and inquiry form.

## Tech Stack & Assets

- Semantic HTML5 with accessibility considerations (skip link, ARIA landmarks, mobile navigation drawer).
- Modern responsive CSS (`css/styles.css`) with CSS custom properties.
- Vanilla JavaScript (`js/main.js`) for interactive UI components (mobile drawer navigation, form feedback).
- Optimized image assets (`assets/images/`).

## Local Development

To run a preview server locally:

```bash
# Python 3
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
